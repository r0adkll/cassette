# 0006: Design process

Date: 2026-10-16 · Status: accepted

## Decision

SRAM red is the hero colour, Material 3 is the fallback component layer, and the look should be unique and
modern. Designs are explored as interactive HTML mockups with real data before any UI is built, then the
chosen direction is spiked as a Compose design system and checked on device. The first iteration explores
four directions: instrument cluster, editorial/Swiss, technical/blueprint and soft modern.
